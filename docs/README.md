# docs/

Tài liệu nghiên cứu. Đọc theo thứ tự:

| File | Nội dung | Khi nào sửa |
|---|---|---|
| [proposal.md](proposal.md) | Thiết kế hệ thống, bộ dữ liệu, toàn bộ research question (RQ), lộ trình, nơi nộp paper | Khi đổi hướng dự án |
| [experiment_plan.md](experiment_plan.md) | Các bước thực nghiệm cho từng RQ: dữ liệu, model, chỉ số, ngưỡng mục tiêu | Khi chốt quyết định hoặc thay đổi thí nghiệm |
| [research/](research/) | Mỗi nhánh một file: RQ chi tiết, giả thuyết, nguồn đọc | Khi literature review |

Trong `research/`:

| File | Nhánh |
|---|---|
| [audio.md](research/audio.md) | Phát hiện giọng người khác (`other_voice`) |
| [camera-position.md](research/camera-position.md) | Vị trí đặt 2 điện thoại (C2, C3) |
| `face.md` (chưa viết) | Xác minh danh tính, head pose, gaze |
| `<nhánh>_literature_review.md` | Bảng ghi chép khi đọc từng bài, tạo khi bắt đầu đọc |

Quy ước: ngưỡng trong tài liệu là **mục tiêu đặt trước**, không phải kết quả. Kết quả thật nằm ở `experiments/`.
