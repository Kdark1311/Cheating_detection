# paper/

Bản thảo paper. Mỗi paper một thư mục con:

| Thư mục (dự kiến) | Paper | Nơi nộp |
|---|---|---|
| `wacv2028/` | Bộ dữ liệu + hệ thống 3 camera + audio | WACV 2028 Applications |
| `audio/` | Phát hiện giọng người khác trong phòng thi | ICASSP 2028 / Interspeech 2028 |
| `face/` | Xác minh liên tục + gaze trong phòng thi | FG / IJCB |

Mỗi thư mục: file LaTeX theo template của hội nghị, `figures/` (hình xuất từ `experiments/`), `refs.bib`. Số liệu trong paper phải lấy từ `experiments/<RQ>/.../metrics.json`, không gõ tay.
